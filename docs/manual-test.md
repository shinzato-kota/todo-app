# 手動テスト手順

JUnitでは検証できない動作（ブラウザ上のJavaScriptの動作、アプリの再起動、リンクによる画面遷移）を、手作業で確認するための手順。

実施した結果は [test-results/manual-test.md](test-results/manual-test.md) に記録している。

サーバー側の処理は `src/test/java` 配下のJUnitテストで検証している。

## 前提

1. `README.md` のセットアップ手順に従い、アプリを起動しておく
2. `db/02_sample_data.sql` を実行し、5つのステータスのタスクが登録された状態にしておく
3. ブラウザで `http://localhost:8080/todo-app/tasks` を開く
4. ブラウザの開発者ツールを開き、「ネットワーク」タブの「キャッシュを無効にする」にチェックを入れる（修正前のJavaScriptやCSSが使われないようにするため）

項目は番号順に実施する。後の項目で、前の項目で追加したタスクを使う。

## 手順

### 1. 再起動してもタスクが残る

**手順**

1. 一覧画面の「タスク追加」から、タイトル「再起動確認」のタスクを登録する
2. アプリを停止する
3. アプリを再び起動する
4. 一覧画面を開く

**期待する結果**

- 「再起動確認」のタスクが一覧に表示されている

### 2. ステータスを変更すると表示が切り替わる

**手順**

1. 一覧画面の「タスク追加」から、タイトル「ステータス確認」のタスクを登録する
2. 「ステータス確認」のプルダウンで、ステータスを次の順に変更する
   進行中 → 保留 → 完了 → 中止 → 進行中 → 未着手
3. 変更するたびに、画面を再読み込みせずにステータス表示が切り替わることを確認する
4. 画面を再読み込みし、ステータス表示を再確認してから次のステータスへ変更する

**期待する結果**

| ステータス | 表示 |
|---|---|
| 未着手 | 通常の表示 |
| 進行中 | プルダウンの背景が青系になる |
| 保留 | プルダウンの背景がグレー系になる |
| 完了 | タイトルに取り消し線が付き、グレーになる |
| 中止 | タイトルに取り消し線が付き、斜体になる |

- 「中止 → 進行中」で、タイトルの取り消し線と斜体が消える
- 最後の「進行中 → 未着手」で、プルダウンの背景が通常の表示に戻る
- 再読み込みの前後で、ステータスと表示が変わらない

### 3. 通信中はプルダウンを操作できない

**手順**

1. 開発者ツールの「ネットワーク」タブで、通信速度を「3G」に設定する
2. 「ステータス確認」のステータスを変更する
3. 応答が返る前に、同じプルダウンを操作しようとする

**期待する結果**

- 応答が返るまでプルダウンが灰色になり、操作できない
- 応答が返ると、再び操作できるようになる

確認後、通信速度の設定を元に戻す。

### 4. 通信に失敗すると選択が元に戻る

**手順**

1. 開発者ツールの「ネットワーク」タブで、通信速度を「オフライン」に設定する
2. 「ステータス確認」のステータスを変更する

**期待する結果**

- 「ステータスの変更に失敗しました。」というダイアログが表示される
- ダイアログを閉じると、プルダウンの選択が変更前の値に戻っている
- プルダウンが操作できる状態に戻っている

確認後、通信速度の設定を元に戻す。

### 5. 一覧と追加画面を行き来できる

**手順**

1. 一覧画面の「タスク追加」を押す
2. 追加画面で何も入力せずに「キャンセル」を押す

**期待する結果**

- 手順1で、見出しが「タスク追加」の画面に移動する
- 手順2で、一覧画面に戻り、タスクは増えていない

### 6. 一覧と編集画面を行き来できる

**手順**

1. 「ステータス確認」の「編集」を押す
2. タイトルを変更せずに「キャンセル」を押す

**期待する結果**

- 手順1で、見出しが「タスク編集」の画面に移動し、入力欄に「ステータス確認」が入っている
- 手順2で、一覧画面に戻り、タイトルは変わっていない

### 7. 編集したタイトルが一覧に反映される

**手順**

1. 一覧画面の「タスク追加」から、タイトル「編集前」のタスクを登録する
2. 「編集前」の「編集」を押す
3. タイトルを「編集後」に変更して「保存」を押す

**期待する結果**

- 一覧画面に戻り、そのタスクのタイトルが「編集後」になっている
- ステータスは編集前から変わっていない

### 8. 削除の確認でキャンセルすると削除されない

**手順**

1. 一覧画面の「タスク追加」から、タイトル「削除キャンセル確認」のタスクを登録する
2. 「削除キャンセル確認」の「削除」を押す
3. 確認ダイアログで「キャンセル」を押す
4. 画面を再読み込みする

**期待する結果**

- 確認ダイアログに「削除キャンセル確認」が表示される
- キャンセル後も、「削除キャンセル確認」が一覧に残っている

### 9. 削除するとその行だけが消える

**手順**

1. 一覧画面の「タスク追加」から、タイトル「削除確認」のタスクを登録する
2. 「削除確認」の「削除」を押す
3. 確認ダイアログで「OK」を押す
4. 画面を再読み込みする

**期待する結果**

- 画面を再読み込みせずに、「削除確認」の行だけが一覧から消える
- 再読み込み後も、「削除確認」は表示されない

### 10. 最後の1件を削除すると0件の表示になる

**手順**

1. 一覧に表示されているタスクを、項目9と同じ方法で1件ずつ削除していく
2. 最後の1件を削除する

**期待する結果**

- 最後の1件を削除した時点で、表が消えて「タスクはありません」が表示される
- 画面の再読み込みは発生しない

確認後、`db/02_sample_data.sql` を実行してデータを戻す。
